# ML Practice

A dependency-free English study quiz built from 18 recovered machine learning questions.

Open `index.html` directly or serve this directory with any static web server. Features include instant explanations, numeric answers, shuffled questions and options, saved progress, a personal mistake bank, repeat attempts and an answer guide. Browser storage stays on the current device.

Questions 3 and 15 were not visible in the source photographs. Question 10's dataset was reconstructed as 0, 2, 4, 6, 8. Question 14 uses a negative R² without reproducing the unreadable exact value.

For GitHub Pages, publish the `main` branch from `/ (root)`.
